# ContactHub 1.0.0 release notes

First complete course release: contact CRUD, search/filter/pagination, favorites, unlimited typed contact methods, live statistics, Excel export/import/template, responsive React UI, isolated automated tests, CI, and persistent Docker deployment configuration.

Known operational requirements: a public URL still requires a user-provided cloud server, DNS/firewall/TLS configuration, and deployment. Course submission screenshots, demo video, individual blog publication, remote pull request, and GitHub release must be created from the real running project by an authorized user.
